# React + Vite# rrr— 
### Diseño, Dirección de Arte & Estrategia Visual

> "Ya eres imposible… también podría ser interesante."

**rrr—** es un espacio digital minimalista diseñado para albergar un manifiesto creativo, un portfolio seleccionado y un blog de pensamiento visual. Este proyecto busca la máxima expresión con la mínima carga cognitiva, priorizando la tipografía, el espacio negativo y la intención detrás de cada píxel.

---

## 🎨 Concepto Visual
El sitio utiliza una paleta de colores basada en el azul profundo (`#2b44c0`) para su versión *light* y un negro puro para el modo *dark*, creando una experiencia inmersiva y editorial.

* **Tipografía:** Inter (vía Google Fonts) para máxima legibilidad y modernidad.
* **Interacción:** Transiciones suaves de color y animaciones de revelado (`revealUp`) para guiar la mirada.
* **Estructura:** Single Page Application (SPA) con navegación por componentes dinámicos.

## 🛠️ Tecnologías
Este sitio fue construido utilizando herramientas de alto rendimiento para garantizar una experiencia fluida:
* **React + Vite:** Para una arquitectura de componentes rápida y reactiva.
* **CSS-in-JS:** Estilizado mediante variables de entorno para facilitar el cambio de temas (Light/Dark).
* **GitHub Pages:** Despliegue automatizado para alta disponibilidad.

---

## 📖 El Manifiesto
El corazón del sitio es una pieza literaria sobre la existencia y la curiosidad, diseñada para ser leída con calma. Cada párrafo aparece con un retraso calculado para generar un ritmo de lectura cinematográfico.
